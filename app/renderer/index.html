Usage

Every edit Claude made with its file tools in this tab, newest first. Click one to see that edit; "Undo back to here" reverts everything after it.

Your scratchpad for this tab. Saved automatically. Claude only sees it when you press Send.

PowerShell commands run on session events. They get META_EVENT, META_SESSION and META_PROJECT in their environment. Leave a box empty to do nothing.

Reloads by itself when files change.

Servers listening on a port that were started from one of your IDE terminals. Refreshes every few seconds.

Snippets are prompts you reuse. Ctrl+Shift+P inserts one into the active Claude tab without sending it.

Each task runs on its own copy of the repo (a git worktree), one after another. Nothing touches your files until you press Apply.
